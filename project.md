Goal : I want to create a new project that will display UEFA club ranking in real time.

Functionalities : 
- This project will be developed with a frontend and a backend. 
- A backend will be implemented using Node.js and Express to fetch data : uefa clubs lists engaged in european competition for a season, uefa points calculation rules for all competition and live score data from external APIs. In the first draft, all backend data will be mocked, but in the final version, it will be fetched from the APIs.
- The frontend will display the rankings in a user-friendly interface, allowing users to filter and sort the data based on various criteria such as country, league, and club performance.
- The single-page frontend will have two tabs: a global club ranking and a global association ranking, both using five-season coefficients ending in the selected season. The active-season view is provisional, not UEFA's fixed current-season seeding ranking.
- Each main row shows global rank, movement versus the preceding season, five labelled season contributions, and the final coefficient. Season columns can be sorted without changing the displayed global rank.
- Expanding a club shows the selected season's competition, points per game and round, separately labelled bonuses and adjustments, and season total. Confirmed non-participation is explained as zero.
- Expanding an association shows its selected-season clubs grouped by competition, with competition subtotals. The association coefficient follows UEFA's association-specific rules and divisor, not a sum or average of club coefficients.
- Retain game and round details for every selectable season and sufficient older coefficients and rank inputs for historical five-season windows and prior-season comparisons.
- Different competition formats and stage lengths must be represented consistently without treating unknown or inapplicable entries as zero.

Method : we will use github copilot to create the whole project, with github spec kit as a guide method to do so. We will respect the following steps in that order : constitution, specification, plan, tasks, implementation, testing, and deployment. Each step will be documented in the respective markdown files generated by the spec kit and will be stored in a docs/ directory.

Technology : the frontend will be developed using React.js with vite framework, typescript and tailwindcss for styling. The backend will be developed using Node.js and Express, with data fetching from external APIs. We will also use a mongo database to store the fetched data for caching and performance optimization.
